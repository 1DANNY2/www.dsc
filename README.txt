# Danny Shoe Collection

Clean white shoe e-commerce starter website.

## Files
- `index.html` - main website
- `css/style.css` - styling
- `js/script.js` - products, cart, search, filters and forms
- `images/` - put your real shoe images here

## Adding your images
Replace the placeholder image files with:
- hero-shoe.jpg
- shoe1.jpg through shoe8.jpg

The HTML/JavaScript already points to those filenames.

## Important
The checkout UI is prepared for integration with a real payment gateway. It does NOT process real payments yet. Do not collect or store card numbers in this static site.

Prices are displayed in Zambian Kwacha (K/ZMW).
